# Web3 Event-as-a-Service (Core Architecture)

Этот репозиторий фиксирует архитектурные решения для MVP сервиса, доставляющего нормализованные Web3-события через webhooks и HTTP API.

> **Образец кода.** Опубликовано, чтобы показать, как я проектирую и пишу backend-системы:
> outbox-доставка, идемпотентность, нормализация событий. Это архитектурное ядро MVP,
> а не готовый продукт. Все права защищены — см. [`LICENSE`](LICENSE).

## Что внутри

- `docs/canonical-event.md` — контракт события, JSON Schema, правила финальности и идемпотентности.
- `docs/subscriptions.md` — модель подписок и фильтров, стратегия матчинга и индексов.
- `docs/delivery-webhooks.md` — outbox, ретраи, подпись, replay.
- `docs/storage-api.md` — схемы хранения, индексы, HTTP API и ретеншн 90d.

## Основные принципы MVP

- Источники: EVM logs (Ethereum + L2), расширяемые адаптерами.
- Доставка: at-least-once, детерминированный `event.id`, финальность по подтверждениям (12 по умолчанию).
- Мульти-тенантность: Projects + API keys.
- Ретеншн: 90 дней для событий и доставок.
